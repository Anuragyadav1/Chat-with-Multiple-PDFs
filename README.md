## 🚀 Features  
- **Multi-PDF Support**: Upload and process multiple PDFs at once.  
- **Semantic Search**: FAISS-powered vector embeddings for accurate answers.  
- **Gemini Pro Integration**: Leverage Google's LLM for natural language responses.  
- **Streamlit UI**: Intuitive interface for non-technical users.  

## ⚙️ Tech Stack  
- **Backend**: Python, LangChain, Google Generative AI  
- **Vector DB**: Facebook AI Similarity Search (FAISS)  
- **Frontend**: Streamlit  
- **Embeddings**: Google Gemini
